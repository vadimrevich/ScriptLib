# Создать правило для запуска VBA скрипта в outlook

Чтобы создать правило для запуска VBA-скрипта в Outlook, нужно:

- Открыть редактор VBA в Outlook (Alt+F11). Скрипт можно добавить в новый модуль или в объект ThisOutlookSession. Это скажется только на имени модуля, на который потом нужно будет ссылаться, создавая правило. 5
- Вставить в редактор код скрипта. Например, чтобы проверить работу скрипта, можно вставить код, который выведет всплывающее окно с темой полученного сообщения. 5
- Создать правило. Выбрать, на какое событие будет вызываться скрипт. Например, скрипт будет срабатывать на все сообщения, которые адресованы на определённый адрес. 5
- Выбрать действие «Run a script» и скрипт, добавленный в VBA-редактор. 5

В некоторых версиях Outlook, особенно в последних обновлениях, опция «Запустить сценарий» может быть отключена по умолчанию в качестве меры безопасности. Чтобы активировать её, нужно изменить определённые параметры реестра:

- Нажать Win+R, чтобы открыть диалоговое окно. 4
- В этом диалоговом окне ввести regedit и нажать кнопку OK. 4
- В окне редактора реестра перейти по пути: HKEY_CURRENT_USER\Software\Microsoft\Office\16.0\Outlook\Security. 4
- Щёлкнуть правой кнопкой мыши на ключе «Security» и выбрать «Новый» > «Параметр DWORD (32 бита)». 4
- Назвать созданный DWORD как EnableUnsafeClientMailRules. 4
- Дважды щёлкнуть по созданному DWORD, чтобы открыть диалоговое окно «Изменить значение DWORD (32-бит)». 4
- Ввести 1 в поле «Значение» и нажать OK. 4
- Перезапустить Microsoft Outlook. 4

После этого можно будет найти и использовать опцию «Запустить сценарий» при создании правил в Outlook. 4
